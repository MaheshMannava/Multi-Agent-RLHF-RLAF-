# Interactive Code Debugging with Multi-Agent Reinforcement Learning

This project implements the core ideas from the baseline paper:

> Krishnamoorthy, Ivaturi, and Ahmadnia. “Multi-Agent Reinforcement Learning for Interactive Code Debugging with Human Feedback and Memory.” RANLP 2025.

Reference: <https://aclanthology.org/2025.ranlp-1.70.pdf>

## Project objective

Build and evaluate an interactive Python debugging assistant with:

1. A Syntax Agent for compiler and structural errors.
2. A Logic Agent for test-driven behavioral errors.
3. PPO-based policy learning.
4. Simulated and later real developer feedback.
5. Episodic memory using FAISS retrieval.
6. An alternating multi-agent controller.

## Current status

Phase 1 has started: a 20-sample pilot dataset and subprocess-based evaluator are implemented and tested. The evaluator checks syntax compilation, runs logic tests, and verifies that corrected programs pass. No reinforcement-learning model has been trained yet.

## Implementation principle

The paper does not fully specify how complete patches are generated by the PPO policies. Our reproducible implementation will therefore generate structured candidate patches using repair templates and test-guided mutation operators. PPO will select and refine candidates rather than directly generating unrestricted source code.

## Planned sequence

1. Dataset and execution evaluator.
2. Candidate patch generation.
3. Rule-based and supervised baselines.
4. Syntax and Logic environments.
5. Individual PPO agents.
6. Alternating multi-agent controller.
7. Simulated feedback and reward learning.
8. FAISS episodic memory.
9. Human-feedback interface.
10. Ablation studies and final evaluation.

See [docs/implementation-plan.md](docs/implementation-plan.md) for the detailed plan.
