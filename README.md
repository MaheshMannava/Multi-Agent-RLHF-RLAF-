# SWE-bench Lite local pilot

This project contains a local pilot for loading a SWE-bench Lite development issue, recording a candidate patch, and evaluating it against a regression test.

The single-request controller has generated a free-model patch that passed one local regression test file. Local results are not official SWE-bench scores.

For the code flow, verified results, limitations, and commands to demonstrate the work, see [the local pipeline guide](docs/local-pipeline.md).
